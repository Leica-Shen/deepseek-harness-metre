# 纵向分布与填空

「下半页空」和「元素挤在一起」是同一件事的两面：**内容高度与页面高度不匹配**。
2.9 的处理是把元素往下推（`safe_y`），推多了就撞、推少了就空。
3.0 把它变成一条分布律。

## 分布律（`studio/compose.py::place`）

给一组块高 `heights` 和一个区域 `area`：

1. 先按固定 `gap` 排。
2. 有剩余空间 → **优先加大组内间距**，但不超过 `max_gap`（一般 40–52pt）。
   加间距是有上限的：超过上限，元素之间就不再是「一组」。
3. 仍有剩余 → **整体下移**，上留 42%、下留 58%（视觉重心略高于几何中心）。
4. 如果剩余超过区域的 34%，说明「这页内容不够撑」，触发**填空**（见下）。

三条禁令：

- 不许把元素等比放大来填空间。
- 不许为了填满而复制内容。
- 不许改页边距来「看起来更满」。

## 填空装置（按语言启用）

| 装置 | 适用语言 | 做法 | 证据 |
| --- | --- | --- | --- |
| 卡片 / 色板 | sweet、paper | 把一组内容放进一个圆角面板，面板外扩 20–26pt | 源 01 的 `DEEBF7` 卡片、源 03 的白便签 |
| 大数字横排 | sweet、iron、grid | 指标页数字按栏宽撑到 90–150pt | 源 02 的 100pt、源 04 的 88pt |
| 年报式指标 | grid、paper | 数字一列、说明一列、细线分行，纵向铺满 | 源 04 的多栏报告页 |
| 结论条 | 全部 | 正文区底部 26pt 处一条「结论/出处」 | 源 01、03、04 的 Note / Lesson 行 |
| 细线导轨 | grid、manifesto | 内容底部一条 0.8pt 短线收口 | 源 03、05 的分栏线与页脚线 |
| 便签 | paper | 每条内容一块白板，轻转 ±0.9°、软阴影 | 源 03 的旋转便签 |
| 引语 | 全部 | 把一句原文放大成引语页，而不是硬撑要点页 | 源 01 P18、源 05 P07 |

**没有**「加一个装饰图形」这一档。装饰不解决空，只解决单调。

## 各类页的默认分布

| 页型 | 分布 | 说明 |
| --- | --- | --- |
| 封面 | 三锚点：标签贴顶、标题 52–60%、底行收口 | 中间留白是设计，不是空 |
| 主张 / 引语 | 光学居中（44%） | 允许大留白；这是「安静页」 |
| 要点 | 顶部对齐 + 组距撑到上限 | 仍空则换 `rail` 变体（标题进左栏） |
| 指标 | 结论先占位，数字在剩余区居中 | 避免「数字排满、结论被挤掉」 |
| 图文 | 正文组在正文区居中；装不下则逐档缩字号 | 缩到 0.6 仍装不下就说明该拆页 |
| 表 / 图 | 撑满：行高按可用高度反算 | 表最短 34pt/行，最长 84pt/行 |

## 节奏与空页

空页不是错，**无意的空页**才是错。`audit` 只对正文类页面（要点/图文/对比/表/图/指标）
检查「内容最低点是否低于 70%H」，对封面、章节、主张、引语、结尾豁免。
