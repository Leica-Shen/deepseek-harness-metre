# 五种设计语言

> 一条纪律：**语言 = 语法，不是页面**。语言里可以有「圆角卡片 + 金色数字」，
> 不可以有「某页那三张图」「那句水印」。指纹清单见 `../studio/cli.py` 的 `BANNED`。

## 怎么选

按**内容密度与气质**选，不按行业选：

| 内容形态 | 选 | 理由 |
| --- | --- | --- |
| 长文、多表格、要放很多信息 | `grid` | 字号克制、细线分栏，密度高也不吵 |
| 短句 + 大图、要气质 | `manifesto` | 大衬线、出血图、留白大 |
| 要有冲击力、要卖 | `iron` | 黑白红、满幅图、字大 |
| 要塞满、要显得热闹 | `sweet` | 卡片 + 色块，信息可以塞 |
| 要轻、要空、要斯文 | `paper` | 宽边际、便签、纸纹 |

一册只用一种。混用会立刻变成「模板拼盘」。

## 语言里不许出现的东西

- 样本水印文案、吉祥物、固定照片、`*-…-*` 记号、巨型首字母（结构规则见审计章）。
- 品牌的 logo 与专名。logo 由使用方传 `logo` 参数，引擎不内置任何标志。
- 通用 AI 审美：渐变紫、玻璃拟态、三栏图标卡、居中大标题 + CTA 按钮、emoji。

## 语言可以「换纸不换骨」

`tone` 决定纸色：`light` / `dark` / `tint` / `sand`。同一语言换纸之后，
字阶、装饰、构图全部不变——这是检验「学的是语法还是页面」的最快方法：
把一册 `grid` 切成深底，它仍然是 `grid`；把样板的某一页搬过来换色，会立刻露馅。
