# 再蒸馏：设计语言通则（不含任何来源信息）

> 口径：5 份样板、72 页的实测统计（本地存档，不随包分发）。
> 只保留「可迁移的判断」，不保留任何页面、文案、品牌或图片。

## 一、密度：三档，不是一档

| 实测覆盖 | 对应语言 | 用在哪 |
| --- | --- | --- |
| 0.70–0.85 | 冲击型 | 提案开篇、结论页 |
| 0.50–0.62 | 通用型 | 大多数正文页 |
| 0.20–0.35 | 安静型 | 引语、价值主张、章节过渡 |

同一册里三档要出现，否则读者会疲劳。连续三页同档 → 换一页。

## 二、边距与标题起点

- 文字左边距 p25：0.35–1.14 in，中位约 0.5 in；
- 标题起点：页高 13%–26%，同一册里固定一个值；
- 右侧留白通常比左侧多 10–20%（视觉重心偏左）。

## 三、字阶与比例

- 实测字阶（pt）：80 / 72 / 48 / 41 / 36 / 32 / 24 / 18 — 不是等差，是**跳档**；
- 标题 : 正文 = **2.4–3.2**；
- 一页 2–5 级，超过 5 级读者分不清主次；
- 数字常比同级文字大 1.5–2 倍，用来「占重量」。

## 四、对齐：居中比想象的多

| | 左对齐 | 居中 |
| --- | --- | --- |
| 冲击型 | 少 | 多 |
| 报告型 | 多 | 少 |
| 文化/品牌型 | 混用 | 标题与引语居中 |

判断法：**短句（≤14 字）居中更稳；长句左对齐更好读**。
垂直方向：模块在带内居中（`MIDDLE`），不要让文字全部顶到上沿。

## 五、圆角与阴影

- 圆角一律 `adj = 0.1667`（短边比例），没有手工微调；胶囊用 0.5；
- 阴影只有一档：blur 15 / dist 5 / dir 45° / alpha 30%，且只出现在「浮起来」的卡片上；
- 不需要层次就不要阴影——三份样板完全没有阴影。

## 六、图片位置四种，轮换

| 位置 | 面积占比 | 特征 |
| --- | --- | --- |
| 通栏（上） | 25–40% 页高 | 章节、报告开篇 |
| 半幅（左/右） | 35–55% 页宽 | 图文页 |
| 框内 | 20–30% | 产品、人物，四周留边 |
| 满幅压字 | ~100% | 封面、结尾、主张 |

同一册里四种都出现、且**不连续两页同一种**，是最容易被误认为「有人设计过」的细节。

## 七、透明与层次

- 压图遮罩：底部渐变 0→72%，不要半透明色块（会显脏）；
- 浅色底板：同一色系 8–15% 的 tint，用来分组，不用描边；
- 深色页：整册 1–2 页，落在能承受反白的页型上。

## 八、可迁移的三条判断

1. **先定密度，再定元素**：密度定了，字号、留白、图片面积才有依据。
2. **一页一个视觉重量**：数字、图、标题三者只能有一个是主角。
3. **版式轮换 > 版式精致**：连续两页同一结构，读者立刻感到"模板"。
