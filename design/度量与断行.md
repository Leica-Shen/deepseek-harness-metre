# 度量与断行

## 为什么必须自己断

2.9 的溢出与重叠，根因是**估行**：`行数 ≈ 字数 × 字宽 / 可用宽`。
中英混排时 1 个汉字 ≈ 1.0em，1 个拉丁字母 ≈ 0.5em，误差随混排比例放大到 ±40%。
估少了 → 文本框高不够 → 压到下一个元素；估多了 → 半页空白。

3.0 做三件事：

1. **真实度量**：`studio/textmetrics.py` 用 PIL + 系统字体文件量每个字的 advance；
   CJK 与全角标点固定 1.0em（这一点与实际渲染一致，不需要字体文件）。
2. **最优断行**：DP 求全段最小代价，而不是逐行贪心（见下）。
3. **写死断行**：把结果写成 `a:br`，并关掉 `auto_size`、保持 `word_wrap`。
   这样 PowerPoint / WPS / Keynote 看到的断行与设计时完全一致。

## DP 代价函数

对每个可行断点 `j`：

```
cost(j) = min over i { cost(i) + (1 - width_used/width)^2 × 1000 + penalty(j) }
```

- `penalty = 0`：前一个原子是空格，或前一个字符是标点 `，、。；：！？）》」』…—`。
- `penalty = 250`：汉字之间硬断（合法但有代价）。
- `penalty = 390`：断点后的字是虚词（`的了着过是在和与及或而就都也又很更最把被让给对从向`）——
  中文排版忌讳「的」起行。
- `penalty = 40000`：拉丁词内部（几乎禁止）。
- 末行不计 raggedness。

## 避头尾与不可拆单元

- 行首禁则：`，。、；：？！）】」』〉》”’%‰℃·—` 不得起行。
- 行尾禁则：`（【「『〈《“‘` 不得收行。
- `——` 与 `……` 先合并成一个原子，破折号绝不被拆到两行。
- 收尾引号（`”’」』）】》〉`）跟着前一段走，不单独成行。

## 标题为什么先切意群

汉字词没有空格，DP 无法知道「飞机」是一个词。做法是先按标点切意群
（`Airbus：一架飞机的生意，` / `从交付、订单到产能的三重奏`），
贪心装行；只有单个意群超宽时才在字间 DP 断。

`fit_display()` 在候选字号里从大到小试，要求：行数 ≤ 上限、末行不是孤字
（末行宽度 < 34% 可用宽 → 否决，< 46% → 降级），装得下。所以标题会
宁可小一号，也不留一个孤零零的「仪式。」。

## 与渲染器的偏差

实测（1600px 出图，Keynote）：40pt 文本的 cap top 与文本框顶差 2px，60pt 差 4px，
即约 `0.06 × 字号`。高度方向 `n × 字号 × 行距` 与实际渲染吻合（40pt/1.12 实测 43px vs 44.8pt）。
因此不需要补偿系数；但换字体、换渲染器时仍建议 `--png` 复核一次。

## 行距

行距一律写**精确点数**（`spcPts`），不用倍数。倍数在不同渲染器下对「单倍行距」的定义
不同（字体 ascent+descent+linegap），会带来 5–15% 的高度漂移；精确点数没有这个问题。

| 用途 | 行距 |
| --- | --- |
| 封面 / 主张 | 1.06–1.14 × 字号（语言而定） |
| 标题 | 1.10–1.22 |
| 正文 | 1.42–1.55 |
| 小标签 | 1.2 |

## 已知边界

- PIL 不做字体回退：每个字符必须自己按 script 分派到 latin / ea 字体（已实现）。
- 系统缺字时（如展示字体缺 `¥`）会把符号路由到中文字体；仍缺则渲染器回退，
  形状可能变（`¥` 可能显示为无横杠的 Y）。交付前用 `--png` 看一眼货币与符号。
