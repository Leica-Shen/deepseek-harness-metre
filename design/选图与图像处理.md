# 选图与图像处理

72 页里有 179 张图（含背景图），图片是这套 PPT 的主要信息载体。
选错图，版式再对也不像；选了不处理，就成了「贴图」。

## 一、选什么

按角色排优先级（`iron`/`manifesto` 可用满幅图，`grid`/`paper` 以文档物为主）：

1. **产品/物件特写**：干净背景、单一主体、能看材质。
2. **人在场景里**：不是摆拍证件照；有动作、有环境信息。
3. **空间/建筑**：用于建立场所感；注意透视不要歪。
4. **过程物**：手稿、草图、模型、屏幕截图——证明「真的做过」。
5. **纹理/色场**：只在没有实拍时用，且必须程序生成，不许找网图充数。

**不要**：带别的品牌 logo 的图、带水印的图、拼贴图、AI 生成的具象图。

## 二、比例

显示框比例是硬规格，原图比例不是。五档：`1:1`、`4:3`（1.33）、`3:4`（0.75）、`16:9`（1.78）、`2:3`（0.667）。
引擎按目标框比例裁切，绝不拉伸：`_crop_for()` 计算 `srcRect` 的四边百分比。

## 三、裁切与焦点

- 照片一律 `fit=cover` + `focus=(fx, fy)`，`focus` 是主体在**原图**里的相对位置。
  引擎据此决定往哪边裁，保证主体不被切掉。
- 透明底素材（PNG/ SVG）走 `fit=contain`，整体放入、不裁切。
- 人像默认 `focus=(0.5, 0.42)`（眼睛在偏上三分之一）；产品默认 `(0.5, 0.5)`。

## 四、压字

文字压在图上必须加**渐变暗幕**，不许硬边色块（2.9 的「谢谢」页就是硬边，像贴了一条黑胶带）。

| 语言 | 暗幕 | 方式 |
| --- | --- | --- |
| iron | 58% | 全幅压暗（源 02 的黑白高对比照片） |
| manifesto | 38% | 底部 55% 渐变（源 05 的天空渐变） |
| sweet | 26% | 全幅轻压（源 01 的浅底产品图） |
| grid / paper | 0% | 不压字：文字与图分栏 |

渐变用真实 `gradFill`（两停）而不是叠几层色块，WPS 与 PowerPoint 都支持。

## 五、灰阶与单色

`iron` 允许 `mono: true` 把照片转灰并自动对比度（烘焙进临时 JPEG，不依赖渲染器支持
`a:grayscl`）。转换放在 `_bake()`，按 (路径, mtime) 缓存。

## 六、去重

同一张图在一册里出现两次以上，`audit` 会报「重复表述」；同一页两张同图直接视为错误。
图片的许可与来源写进内容 JSON 的 `source` 字段，随页脚一起输出。

## 七、图片主色决定这一页的颜色

样板里最容易被忽略的一条：**底色不是设计出来的，是从图里取的**。

- 源 05 P06：鞋是浅蓝，整页纸就是浅蓝；面板是同一个蓝的更浅档。
- 源 04 P01：伞面是蓝紫，页底就是极浅的蓝紫。
- 源 01 P10：甜点是奶油与树莓，页底就是奶油，边框是树莓色。

引擎实现（`studio/palette.py`）：

1. 缩到 96×96，丢掉近白（L>0.94）与近黑（L<0.05）像素；
2. 4bit/通道分桶，按 `0.25 + 饱和度` 加权，取权重最高的 6 桶加权平均作 `main`；
3. 主色过淡（饱和度 < 0.18）时往饱和方向提 0.18，避免「有图但页面没颜色」；
4. 派生 `light = mix(main, white, 0.62)`、`pale = mix(main, white, 0.88)`、
   `deep = mix(main, black, 0.42)`。

用法：

| 语言 | `palette_mode` | 纸 | 面板 | 强调色 |
| --- | --- | --- | --- | --- |
| sweet / iron / manifesto | `both` | pale 混纸 | light | main（过对比度后） |
| paper / grid | `tint` | pale 混纸 | light | 仍用语言原色 |

文字颜色**不跟图走**——永远用墨色或反白，这是可读性底线。

## 八、联网取图与三种「非方图」用法

`studio/images.py` 走 Wikimedia Commons API：

```bash
python3 -m studio.cli fetch assets/咖啡 "coffee roasting|espresso latte art" --n 6
```

- 只收 CC0 / CC BY / CC BY-SA / PD；`iiprop=extmetadata` 里取 `LicenseShortName`、
  `Artist`、`LicenseUrl`、`descriptionurl`，落成 `来源.json`。
- 只要横图（宽高比 ≥ 1.05）且宽度 ≥ 1200px；同一标题只取一次。
- 下载用系统 `curl` 兜底（urllib 在本机偶发 TLS 握手超时）。
- 生成后商品里保留 `来源.json`；CC BY / BY-SA 要在成品里署名。

三种「非方图」用法（样板里都有对应物：源 04 的六边形伞面、源 01 的圆形产品裁切）：

| 用法 | 实现 | 什么时候用 |
| --- | --- | --- |
| 形状填充 | 形状的 `spPr` 写 `<a:blipFill>` + `stretch` | 圆形头像、圆角产品、椭圆色块 |
| 文字填充 | run 的 `rPr` 写 `<a:blipFill>` | 封面/主张页的大标题；**图必须够亮**（平均亮度 ≥ 0.52），否则自动退回纯色 |
| 满幅背景 | 满幅矩形 + 渐变暗幕 | 封面、结尾、章节页 |

实现细节：`_image_rid()` 先 `add_picture` 拿到 `r:embed`，再把临时形状从 XML 里删掉，
避免包里多一张重复图；`_apply_blip()` 负责按 schema 顺序插 `<a:blipFill>`。

## 九、全册色温与单页色温

- 单页：`palette.py` 从**这一页的图**取色。
- 全册：`build_deck()` 先取 `palette_from`（没有就用第一张出现的图）算出 `deck_pal`，
  没有图的页面继承它。于是「咖啡册」整册偏暖，「机房册」整册偏冷，但每页仍可被自己的图改写。
