# 判断清单（Metre 的骨架）

## 一页只回答一个问题

写不出「这一页的结论」这句话，就说明这页还不该存在。

## 三种页面的密度

- 主张页：1 句话 + 0–1 个证据。留白 ≥40%。
- 证据页：1 个结论 + 3–5 条支撑。覆盖 50–62%。
- 数据页：1 个数字 + 1 句解释。数字占视觉重量 60% 以上。

## 先定轴，再放东西

1. 页边距（均匀）；
2. 标题起点（全册一致，13–19% 页高）；
3. 正文左轴（一条，含悬挂标记的偏移）；
4. 页脚（页码 + 来源，右对齐或左对齐固定一侧）。

四个轴定完，再往里填内容。

## 什么时候该拆页

- 一条要点超过 3 行；
- 两个数字都想当主角；
- 图和表想同时出现且都重要；
- 标题需要两行以上才说得清。

## 什么时候该去掉装饰

装饰只在「没有它页面会散」时保留。判断方法：遮住装饰看页面是否还成立——
成立就删。
